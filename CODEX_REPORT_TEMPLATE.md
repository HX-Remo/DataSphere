# Codex Report Template

Codex should copy this structure into `CODEX_REPORT.md` after each implementation task.

## Summary

Briefly describe what changed and why.

## Files Changed

- `path/to/file`: what changed

## Behavior Added

Describe the user-visible or architecture-visible behavior added by the task.

## Tests Added or Updated

List tests and what each one proves.

## Validation Commands Run

```bash
# command here
```

Include pass/fail results. If a command could not be run, say why.

## Known Limitations

List any limitations, skipped cases, or technical debt.

## Safety and Privacy Notes

Confirm whether the change reads, writes, uploads, moves, renames, or deletes user data.

## Suggested Next Task

Suggest exactly one next task for Claude to consider when updating `NEXT_CODEX_TASK.md`.
